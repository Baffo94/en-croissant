# Stockfish

`stockfish-19-lite-single.js` / `.wasm` come unmodified from the npm package
[`stockfish@19.0.1`](https://github.com/nmrugg/stockfish.js) (Stockfish.js 19,
lite single-threaded build, GPL-3.0). Lite = small NNUE network (~1.8 MB), single
thread = runs in the Android WebView without cross-origin isolation.
